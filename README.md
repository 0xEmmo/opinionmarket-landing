# OpinionMarket Market Floor

A premium, front-end-only OpinionMarket product prototype for an interview submission. The rebuild takes information-hierarchy cues from prediction-market products while using an original Nigerian editorial direction: evergreen surfaces, warm ivory cards, market green signal accents, SVG category icons, image-led market moments, and a responsive product shell.

## Included interactions

- Category rail filters the shared illustrative market dataset.
- Search and sort controls update the visible market feed.
- Market cards, trending, ending-soon, and pulse panels open the same demo ticket flow.
- The floating quick-stake control opens a swirl-style quick-picks sheet; tapping it again reshuffles the suggestions.
- Demo stake tickets provide selectable outcomes and amounts, but never process money, orders, deposits, or authentication.
- Responsive desktop and mobile navigation, keyboard focus, reduced-motion support, and explicit illustrative-data messaging.

## Run locally

Open `index.html` directly, or serve the folder with any static server. `app-ui.html` mirrors the same experience for compatibility with the original two-file prototype.

All market names, values, odds, activity, imagery, wallet balance, and ticket behavior are illustrative demo content.

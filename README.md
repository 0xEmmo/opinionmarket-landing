# OpinionMarket Landing Page

Premium landing page concept for **OpinionMarket** (Task 2 – Interview submission).

## Live preview
Open `index.html` in any browser, or enable GitHub Pages on this repo.

**Repo:** https://github.com/0xEmmo/opinionmarket-landing

## Features
- Mobile-first dark theme with premium visual design
- Clear “How it works” + probability explainer with Naira example
- Market cards with images so users can see what they are trading
- Horizontal category filters (Trending / Sports / Politics…)
- Deposit confidence section
- Interactive bottom ⚡ button → swirl popup with quick stake suggestions that shuffle on each tap
